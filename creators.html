Les bonnes questions.

Mon audience paie-t-elle plus cher ?

Non. Le prix est le même avec ou sans votre code. Le code sert uniquement à vous attribuer l’abonnement.

Sur quel montant la commission est-elle calculée ?

Sur le montant hors taxes payé par l’abonné : 50 % pour son premier mois, puis 30 % chaque mois tant qu’il reste abonné.

Quand suis-je payé ?

Chaque mois, 30 jours après le paiement de l’abonné, afin de couvrir les éventuels remboursements. Le versement a lieu dès 50 €, 50 £ ou 50 $ de commissions accumulées.

Que se passe-t-il si un abonné résilie ?

La commission s’arrête avec son abonnement. Les commissions déjà versées restent acquises ; un paiement remboursé n’ouvre pas droit à commission.

Comment un abonné utilise-t-il mon code ?

Il le saisit dans le champ « Code créateur » lors de la création de son compte Strate.
