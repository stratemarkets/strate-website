      The language

      This page describes the whole StrateScript language: how a script is laid out, what it can declare, and how values, variables and history work. Data sources (bars, trades, the order book) have their own pages: Market data and Order flow.

      How a script runs#

      • The body of the script (its top-level statements) runs once per bar, from the oldest bar to the newest.
      • Event handlers (on trade, on order, on match, on book, on session, …) and patterns run on market events, in exchange order. All events of a bar run before the body of that bar. See Patterns, clocks and signals.
      • Patterns declared with on: bar are evaluated after the body of each bar.
      • On a live chart, the last bar is recalculated as new data arrives. Each recalculation starts again from the state of the previous bar, so a value is never counted twice.

      Lexical rules#

      ElementRule
      EncodingUTF-8 text. Names (identifiers) are ASCII only: [A-Za-z_][A-Za-z0-9_]*. A name with an accented letter gives E005.
      Comments// … to the end of the line, and /* … */ over several lines (not nested; an unclosed /* gives E001).
      Numbers20, 0.5, 1_000_000 (underscores as separators), 1e3, 2.5e-1. Write 0.5, not .5.
      DurationsA number with a unit attached, no space: ns us ms s m h d w. m is minutes (there is no month unit). 1.5h is allowed.
      Strings"…" on a single line. Escapes: \n, \t, \", \\. A line break inside a string gives E002.
      Colors#RRGGBB or #RRGGBBAA in hexadecimal (#26a69a, #26a69a80 for 50% opacity). Anything else gives E003.
      QuantitiesA number, a space, then a unit word: 4 ticks, 2 points, 2.5 usd. See Units. 4ticks (no space) gives E004.

      Reserved words cannot be used as variable names: indicator research strategy pattern import as from fn type enum method var state const persist on when if else for in while return break continue and or not true false na self.

      Built-in names such as close, plot or buy are not reserved. Assigning to one hides it for the rest of the script: after close = 5, close is 5. Avoid it.

      Built-in text constants. A few names stand for the text of the same spelling, so they can be written without quotes: buy, sell, bid, ask, long, short, solid, dashed, dotted, left, right, both, center, full. side: right is the same as side: "right", and mbo.levels(bid, 3) the same as mbo.levels("bid", 3). This guide uses both forms.

      End of statement. A statement ends at the end of the line or at ;. A line continues on the next one when:

      1. it is inside ( … ) or [ … ];
      2. it ends with an operator, a comma, ?, : or .;
      3. the next line starts with and, or, ?, :, ., .., *, /, %, +, a comparison or else.

      A line that starts with - is a new statement, not a continuation.

      StrateScript
      x = 1 +
  2
y = (1
  + 2)
ok = true
  and false
print(x, y, ok)   // → 3 3 false
      StrateScript
      n = 1_000_000 + 2.5e-1
d = 250ms + 1.5s
c = #26a69a80
s = "tab:\t quote:\" newline:\n"
print(n, d, c)   // → 1000000.25 1750ms #26a69a80

      The header#

      Text
      indicator "Name" { key: value, key: value }

      There is at most one header, and it must come before any other statement (E104). Settings are separated by commas or line breaks. A value is an expression or an object { … }.

      Unknown keys are ignored without an error. A misspelled key (latancy: 60ms) silently falls back to the default. Check the spelling of header keys against the tables below.

      Values and types#

      Types are dynamic: a variable holds whatever value is assigned to it.

      TypeWritten as / comes fromNotes
      number20, 0.5, 1e364-bit floating point. Any non-finite result (division by zero, sqrt(-1)) becomes na.
      booltrue, false
      string"text"Joined with +, compared alphabetically.
      color#rrggbb[aa], rgb(), alpha(), mix(), input.color()Only == and !=. str(color) gives #rrggbbaa.
      duration5s, 250ms, input.duration(), the difference of two timesNanosecond precision.
      timebar.time, event.time, now(), .time fieldsAn instant (nanoseconds since 1970, UTC).
      nanaA missing value.
      list[1, 2, 3], array()A reference (see Collections).
      map, ring, windowmap(), ring(n), window(d)References.
      objectan instance of a custom typeA reference.
      functionfn(x) { … }, or the name of a function of the script
      plot handlereturned by plot, histogram, candle, level, hline, bar_color, bg_colorUsed by fill.
      library objectsfootprint, footprint level, trade, book, order event, match, resting order, level statistics, line, box, label, tableRead their fields with ..

      Type annotations are allowed after a declaration (var x: float = 0), on parameters (x: float) and on return values (-> float). They are documentation only: the engine does not check them. A bare x: int = 3 (without var, state, const or persist) is a syntax error (E103).

      Generic constructors array<T>(), map<K, V>() and ring<T>(n) are accepted, with the same meaning as without the type. Write window(10s), not window<T>(10s).

      Truth. In if, while, and, or, not, ?:, and in the conditions of marker, alert and patterns, true and any finite non-zero number are true. Everything else is false: false, 0, na, strings (even non-empty), colors, lists and objects.

      Operators#

      From lowest to highest precedence:

      1. cond ? a : b (right-associative; only the chosen branch is evaluated)
      2. or, ||
      3. and, &&
      4. not, !
      5. comparisons == != < <= > >= (not chainable: a < b < c gives E114, write a < b and b < c)
      6. .. (ranges, only in for)
      7. + -
      8. * / %
      9. unary -
      10. quantity N unit
      11. call (), field ., index []
      OperandsOperatorsResult
      number, number+ - * / %number. % keeps the sign of the left operand (-7 % 3 is -1).
      string, string+, comparisonsjoined text; alphabetical order
      string + another type+E921: convert with str(x) first
      bool, bool / color, color== !=
      duration, duration+ - → duration; / → number (d / 1s = seconds); comparisons
      duration and numberd * 2, 2 * d, d / 2 → duration
      time − time→ duration
      time ± duration→ time
      duration with a number (other than 0) in + - < …E922: write the number as a duration, or divide the duration by 1s

      **Rules for na:**

      • Any arithmetic with na gives na. Division by zero gives na.
      • **Every comparison with na is false, including !=.** na != 1 is false and na == na is false. Test with na(x).
      • and and or stop as soon as the result is known, and always return a bool.
      StrateScript
      d = 5s + 250ms
t = bar.time + 5m
print(d * 2, d / 1s, (t - bar.time) / 1m, 7 % 3, -7 % 3, 7 / 0)   // → 10500ms 5.25 5 1 -1 na
print(na != 1, na == na, not (na == 1), "a" < "b")                 // → false false true true

      Variables and scope#

      FormWhereLifetimeHistory x[n]
      x = expr (first assignment at the top level)bodyA series: reset to na when each bar opens, then computed again.yes
      var x = exprtop level only (E903 elsewhere)Initialized once, then keeps its value from bar to bar.yes
      state x = exprtop level onlySame as var. Use it as a reminder that the value is shared with event handlers.yes
      const x = exprtop level onlyEvaluated once, on the first bar (const k = close freezes the first close). Assigning to it gives E909.yes
      persist x = exprtop level, named indicator onlyLike var, and also saved durably between restarts of the app. See below.yes

      Scope rules:

      • The first assignment y = … inside a block (if, for, while) creates a variable local to that block. After if c { y = 5 }, reading y outside the block gives E930. Declare it first at the top level (y = na).
      • Assigning to a name that already exists at the top level, from a block, a function or a handler, changes the top-level variable. This also holds inside a function: fn f() { g = 2 } changes the top-level g.
      • Functions see their parameters, their own locals and the top-level variables, but not the caller's locals.
      • x += 1 on a name that was never declared gives E905. Declare it first (x = 0).
      • Lists, maps, rings, windows and objects are references: after b = a, b.push(2) also changes a.

      What handlers see. Event handlers and patterns run before the body of their bar. Inside them:

      • var, state, const and persist variables, settings (input.*) and instrument.* hold their current values;
      • body series (plain x = …) are na, because they are reset when the bar opens. Keep anything a handler needs in a state variable;
      • new variables created inside a handler are local to that call.
      StrateScript
      indicator "Counters"
var bars = 0
state seen = 0
const k = 3
bars += 1
seen += 1
up = close > open ? 1 : 0
print(bars, bars[1], seen, k * 2, up[1] + up)
      StrateScript
      last_up = na
if close > open { last_up = close }
print(na(last_up) ? "down bar" : "up bar")

      persist: memory that survives a restart#

      persist keeps a variable's value when the app is restarted, so a long calculation does not start from zero each time.

      • Only in an indicator with a non-empty name (E943 otherwise).
      • Only data can be kept: numbers, texts, bools, lists, maps, rings and objects of your own types. A function, a drawing, a table, a footprint or a book gives E943.
      • The memory is identified by the indicator's name, the instrument, the chart's unit and the settings. Live and Replay have separate memories.
      • It is written only after closed bars, and read back at the first bar at or after the point where it was saved.
      • Bounds: 256 KB, 50,000 values, 16 levels of nesting, 500 memories per mode. Beyond them the memory is simply not written (the previous one is kept) and the script continues.
      • The … menu of the panel shows the memory's status and can clear the live or the Replay memory.
      StrateScript
      indicator "Session high memory" { overlay: true }
persist best = 0.0
if high > best { best = high }
plot(best, #e8c15a, title: "Best high")

      History: x[n]#

      x[n] is the value of x, n bars ago. x[0] is the current value.

      • n is a whole number ≥ 0, constant or computed (it is rounded).
      • A negative index reads the future and gives E911 (close[-1]; the suggested fix removes the -).
      • Beyond the loaded history the value is na. There is no fixed depth limit other than the bars the script received.
      • History works on top-level variables (any kind) and on built-in series named directly: close[1], bar.close[2], volume[3], bar.time[1], session.rth[1]…
      • History does not work on an expression ((close + 1)[1] gives E912: assign it to a variable first), nor on a local variable of a function.
      • If the variable holds a list, map, ring or window, x[i] reads an element, not the history.

      Functions with memory (ema, sma, highest, change, cum, crossover, stats.*, of.cvd, norm.*…) keep their own state for each place they are called. A call inside one of your functions has a separate state for each place that function is called from.

      StrateScript
      mid = (high + low) / 2
k = 2
print(close[1], bar.close[2], mid[k], close[100000])

      The bar still forming: bar.confirmed#

      bar.confirmed is false only on the last bar, and only while it is still forming:

      • on a live chart, or at the Replay cursor;
      • on a time-based chart, while the bar's end has not been reached by the data;
      • on range, renko, volume, delta, tick and reversal charts, until the next bar opens.

      Everywhere else (history, the check, long backtests) it is true. Requiring bar.confirmed for a signal stops it from appearing and disappearing while the candle forms.

      StrateScript
      signal_up = crossover(close, sma(close, 20)) and bar.confirmed
marker(signal_up, shape: "triangle_up", location: "below")
alert(signal_up, "Close crossed above SMA 20")

      Related fields: bar.last (last bar received), bar.index (0 = first bar received), bar.gap (true after a real gap in the data; moving averages restart after a gap).

      Control flow#

      • **if**: if cond { … } else if cond { … } else { … }. } and else may be on different lines.
      • **for over a range**: for i in a..b { … }. Both bounds are included and rounded. If a > b it counts down (3..0 gives 3, 2, 1, 0). A bound that is na skips the loop. More than 10,000 steps gives E906. Ranges only exist in for.
      • **for over a collection**:

      | Form | Visits | |---|---| | for x in list (or ring, window) | values | | for k in map | keys, in increasing order | | for i, x in list (or ring) | index, value | | for k, v in map | key, value | | for t, x in window | time, value |

      The loop works on a copy, so changing the collection inside the loop is safe.

      • **while cond { … }**: more than 10,000 iterations gives E906.
      • **break and continue** act on the innermost loop.
      • **return [expr]** leaves a function (the value is na without an expression), or ends a handler. At the top level of the body, return and break do not stop the bar: they only end the statement they are in, and the following statements still run. Use an if to skip work instead.
      StrateScript
      s = 0
for i in 0..5 {
  if i % 2 == 0 { continue }
  s += i
}
n = 0
while true {
  n += 1
  if n >= 3 { break }
}
a = [10, 20, 30]
txt = ""
for i, x in a { txt += str(i) + ":" + str(x) + " " }
m = map()
m["b"] = 2
m["a"] = 1
for k, v in m { txt += k + "=" + str(v) + " " }
print(s, n, txt)   // → 9 3 0:10 1:20 2:30 a=1 b=2

      Functions#

      Text
      fn name(a, b = 2, c: float = 1) -> float {
  return a + b + c
}
      • Call with positional or named arguments: f(1), f(b: 5, a: 1). A positional argument after a named one gives E115.
      • A parameter with no value and no default gives E915. Extra arguments and unknown names are ignored.
      • Default values are evaluated at each call.
      • Recursion is allowed up to 65 nested calls (E914 beyond).
      • Declare functions at the top level of the script. A function can be called on a line above its declaration.

      Function values. f = fn(x) { return x * k } creates a function value, called as f(3). It keeps a copy of the local variables visible where it was created; top-level variables are read live. The name of a script function is also a value, so it can be passed to list methods such as map, filter or count.

      StrateScript
      fn add(a, b = 10) { return a + b }
fn big(x) { return x >= 2 }
k = 3
mul = fn(x) { return x * k }
fn smooth(x) { return ema(x, 3) }
print(add(1), add(1, 2), add(b: 5, a: 1), mul(2), [1, 2, 3].map(mul).sum(), [1, 2, 3].count(big), smooth(close) != smooth(volume))
// → 11 3 6 6 18 2 true

      Custom types, enums and methods#

      • Type: type Name { field: type, field: type = default }. The name starts with an uppercase letter (E107).
      • Instance: Name { field: value }. A missing field takes its default, or na. An unknown field gives E932, an unknown type E916.
      • Fields are read with z.field and changed with z.field = v or z.field += 1. Only fields of your own types can be assigned.
      • Enum: enum Mode { Waiting, Active } gives values Mode.Waiting, Mode.Active, compared with ==.
      • Method: method Type.name(self, …) { … }, with self as the first parameter. self outside a method gives E917.
      • An instance written directly in an if condition must be in parentheses: if p.x == (P { x: 1 }).x { … }.
      • Instances are references. Kept in a state list or map, they keep their fields from bar to bar.
      StrateScript
      enum Mode { Waiting, Active }
type Zone { top: float, bottom: float, hits: int = 0, mode: Mode = Mode.Waiting }
method Zone.contains(self, p) { return p >= self.bottom and p <= self.top }
z = Zone { top: high, bottom: low }
z.hits += 1
print(z.contains(close), z.hits, z.mode == Mode.Waiting)   // → true 1 true

      Collections#

      All collections are references. Limits: 1,000,000 elements per list or map (E941); ring(n) takes n from 1 to 1,000,000 (E940); window(d) takes a duration > 0 (E940).

      List — […] or array()

      • Read a[i]; a negative index counts from the end; out of range gives na.
      • Write a[i] = v (out of range gives E938); a[a.len()] = v appends; a[i] += v.
      • Fields: a.size, a.length.
      • Changing: push(x, …), pop(), shift(), insert(i, x), remove(i), set(i, x), clear(), sort(desc = false), reverse().
      • Reading: get(i), len() / size(), contains(x), index_of(x) (−1 if absent), first(), last(), slice(from, to), copy().
      • Statistics: sum(), avg() / mean(), max(), min(), percentile(p), median(), stdev() (population), rank(x), zscore(x).
      • With a function: filter(f), map(f), find(f), find_index(f), any(f), all(f), count(f), min_by(f), max_by(f); and sort_by(f, desc = false), which sorts the list in place, like sort(), and returns na. Passing something other than a function gives E933.

      Map — map()

      • Keys are numbers (including times and durations), texts or bools (E939 otherwise). They are kept in increasing order, numbers before texts.
      • m[k] (missing key gives na), m[k] = v, m[k] += v (a missing key counts as 0).
      • Methods: set(k, v), get(k, default), has(k), remove(k), add(k, x = 1), get_or_insert(k, v), keys(), values(), len(), clear(), first_key(), last_key(). Fields size, length.

      Ring — ring(n): keeps the last n values pushed.

      • Methods: push(x, …), get(i), len(), clear(), contains(x), sum(), avg(), max(), min(), first() (oldest), last(), values(), percentile(p), median(), stdev(), rank(x), zscore(x); r[i].
      • Fields: size, length, capacity, full.

      Window — window(10s): keeps the values pushed during the last duration, measured on the time of the event or bar being processed.

      • Methods: push(x[, t]), sum(), avg(), max(), min(), len(), first(), last(), values(), clear(), percentile(p), median(), stdev(), rank(x), zscore(x). Fields: size, length, duration.

      len(x) also works on a list, text, map, ring or window.

      Whole-collection operations (sum, sort, keys…) cost about 1 + n/8 operations of the budget.

      print and str show a list as na, not its content: print its elements, or its len().

      StrateScript
      a = [3, 1, 2]
a.sort()
a.push(7)
m = map()
m.add("n")
m.add("n", 4)
r = ring(3)
r.push(1, 2, 3, 4)
print(a[0], a[-1], a.sum(), a.median(), m["n"], m.get("x", "none"), r.first(), r.sum(), r.full)
// → 1 7 13 2.5 5 none 2 9 true

      Imports#

      Text
      import "path" [as alias] [{ name: value, … }]

      Imports are written at the top level.

      • "strate/patterns/<file>" imports a script from the shipped pattern library (see Patterns, clocks and signals).
      • "my/<name>" imports another script of the same chart whose header carries that name. The imported script must be an indicator or a strategy: a research script cannot be imported this way.
      • An unknown path gives E937.

      Alias. Without as, the alias is the last segment of the path, in lower case, with non-alphanumeric characters replaced by _ (and an i in front if it starts with a digit). Two imports with the same alias give E937.

      What an import gives you. Everything the imported script declares at its top level (variables, settings, functions, clocks) is reached through the alias: tools.basis, tools.dev(x). Its settings appear in your Settings tab, titled alias · Title. Its patterns keep running, and on signal(s from alias) listens to all of them (see Listening to signals; label.new is described in Plotting).

      Overriding values. { name: value } replaces the expression of a top-level declaration of the imported script — typically an input.* — which then disappears from the Settings tab. Naming something the import does not declare gives E937, with the list of its declarations.

      Limits. One level only: an imported script cannot import another (E937). Of an imported script's header, only level_history, flow_history, mbo_history and book_history are used (the longest wins), and an imported mbo_history never moves a strategy's fixed start.

      StrateScript
      indicator "Two absorption definitions" { overlay: true }
import "strate/patterns/absorption_held_volume" as strict { minVol: 99 }
import "strate/patterns/absorption_held_volume" as loose { minVol: 80 }
on signal(s from strict) { label.new(s.time, s.price, "strict") }

      A helper script and a script that imports it. On a chart, both must be scripts of that chart:

      StrateScript
      indicator "Tools"
len = input.int("Length", 20)
fn dev(x) { return x - sma(x, len) }
basis = sma(close, len)
      StrateScript
      indicator "Uses tools" { overlay: true }
import "my/Tools" as tools { len: 50 }
plot(tools.basis, title: "Basis")
plot(close + tools.dev(close), title: "Close + deviation")

      Units#

      A quantity is a number literal, a space, and a unit word.

      UnitValue
      tick, ticksThe number times instrument.tick (a price distance). On ES, 4 ticks is 1.0.
      point, points, contract, contracts, event, events, trade, trades, usd, level, levelsThe number unchanged. The word is only for readability.
      • A unit only follows a number literal. n ticks with a variable n is a syntax error (E106): write price(n) or n * instrument.tick.
      • ticks(distance) converts a price distance into ticks; price(n) converts ticks into a price distance.
      • In enter(stop:, target:), study(stop:, target:, cost:) and costs: { slippage: }, a plain number is a price distance in points: stop: 1 is 1 point = 4 ticks on ES. Write stop: 4 ticks to mean ticks.

      Budget and protections#

      A script cannot freeze the chart. The engine counts the work a script does and stops it with an error when a bound is exceeded.

      Pitfalls#

      • A comparison with na is always false, even !=. Use na(x) or nz(x).
      • The first assignment inside a block creates a local. Declare shared variables at the top level first.
      • return or break at the top level does not stop the rest of the body.
      • const is evaluated on the first bar only.
      • signal(...) always draws a mark, even when its first argument is false: put it inside an if.
      • print and str show a list as na.
      • Unknown header keys and unknown named arguments are ignored without an error: check spelling.
      • sign(0) returns 1. Test x == 0 separately if zero matters.
      • Write window(10s), not window<float>(10s).
