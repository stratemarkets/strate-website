    StrateScript

    StrateScript is the scripting language built into Strate. You use it to write your own indicators, simulated strategies and studies, and run them on any chart. Scripts can read data at every level of detail:

    • bars: OHLC, volume, delta and footprint
    • every trade, one by one
    • the aggregated order book
    • the full order-by-order (MBO) stream: every add, cancel, modify and fill, with queue positions

    Use your AI agent

    The StrateScript skill teaches StrateScript to your own AI agent. It uses the open Agent Skills format.

    • Install it: copy the stratescript folder into your agent's skills folder, or import the .zip in your AI app's settings.
    • Check scripts: when the Strate app is open on the same computer, the agent can check the scripts it writes. Otherwise, paste the script into Strate and read the error it shows.
