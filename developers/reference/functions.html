      Bar data and time#

      Name→Notes
      open, high, low, close, volume, deltanumberSame as bar.open … bar.delta. In handlers: the bar so far. delta may be na.
      bar.buy_volume, bar.sell_volumenumber(volume ± delta) / 2.
      bar.delta_high, bar.delta_lownumberRunning-delta extremes inside the bar; na if unknown and inside handlers.
      bar.time, bar.close_timetimeOpen; known close (next bar's open for non-time bars).
      bar.indexnumber0 = first bar received.
      bar.last, bar.confirmed, bar.gapboolLast bar; bar closed; gap before the bar.
      bar.hour, bar.minute, bar.dayofweeknumberNew York time of the open; 1 = Monday.
      bar.footprintfootprintSee Footprint. E911 inside handlers.
      event.timetimeTime of the event being processed (bar open in the body).
      now()timeEvent time in a handler; close of a closed bar; latest data time on the bar forming.

      Chart and instrument#

      Name→Notes
      chart.timeframetext"1m", "8r", … or na.
      chart.timeframe_secondsnumber0 for non-time bars.
      chart.bar_typetext"time", "range", "renko", "volume", "delta", "tick", "reversal".
      chart.tick_px, chart.bar_pxnumberPixels per tick and per bar.
      chart.row_ticks(min_px = 14)numberRound number of ticks per row, rows at least min_px high. 1 if unknown.
      chart.columns(min_px = 30)numberColumns of at least min_px that fit in a bar (≥ 1).
      instrument.tick, instrument.symbol, instrument.point_valuenumber / text / numbere.g. 0.25 / "ES" / 50.

      Sessions#

      Name→Notes
      session.is_new, session.is_new_day, session.is_last_bar, session.rthbool
      session.daynumberTrading date of the CME session (days since 1970-01-01).
      session.high, session.low, session.overnight_high, session.overnight_low, session.rth_high, session.rth_low, session.ib_high, session.ib_lownumberna when the period's start is missing. Not allowed inside request (E936).
      prev.high, prev.low, prev.closenumberLast complete RTH session. Not allowed inside request.
      session.in(range, time = bar open)bool"HHMM-HHMM[,…][:days]", New York time. Invalid range: E925.

      Example: bg_color(session.in("0930-1030") ? #ffffff08 : na).

      Moving averages and windows#

      All take a length len (a number ≥ 1, rounded to a whole number; E923 below 1 or na), return na until enough values have been seen, and keep a separate state for each call place.

      Function→Notes
      sma(src, len), ema(src, len), rma(src, len), wma(src, len)numberema and rma start from the simple average. They restart after a data gap. A na source value is skipped.
      highest(src, n), lowest(src, n)numberOver the last n values.
      change(src, n = 1)numbersrc − src[n] over the values seen.
      cum(src)numberRunning sum since the first bar (na counts as 0).
      crossover(a, b), crossunder(a, b)boolTrue on the bar where a crosses above (below) b; false if a value is na.

      Example: plot(ema(close, 21)).

      Statistics: stats.*#

      Over the last n values (a number ≥ 1, rounded to a whole number; E923 below 1 or na).

      Function→Notes
      stats.mean(src, n)number
      stats.stdev(src, n)numberPopulation standard deviation.
      stats.zscore(src, n)number0 when the deviation is 0.
      stats.percentile(src, n, pct)numberpct from 0 to 100 (positional or pct:), linear interpolation. E933 if pct is invalid.
      stats.median(src, n)number
      stats.rank(src, n)numberPercentile rank of the current value, 0 to 100, current value included.
      stats.linreg_slope(y, x, n)numberLeast-squares slope; na if the variance is 0.
      stats.corr(y, x, n)numberCorrelation; na if a variance is 0.

      Example: marker(volume > stats.percentile(volume, 100, 95)).

      Normalization: norm.*#

      Compares a value with its own recent values. Window: a duration or a number of values (E933 otherwise). Options: min_count: (default 20), by:, push:. See Normalization.

      Function→
      norm.rank(x, window)Percentile rank 0–100.
      norm.zscore(x, window)Z-score (0 if the deviation is 0).
      norm.ratio(x, window, "median" \| "mean")x ÷ median (default) or mean.
      norm.percentile(x, window, pct)The pct percentile of the values.
      norm.mean(x, window), norm.median(x, window)Mean, median.
      norm.count(x, window)Number of values held.
      norm.unit(x, unit, window)unit: "raw", "rank" ("percentile"), "zscore", "x_median", "x_mean".

      Example: rk = norm.rank(volume, 2h, min_count: 30).

      Math#

      Function→Notes
      abs(x), sqrt(x), log(x) (natural), exp(x), floor(x), ceil(x)numberA non-finite result is na.
      pow(x, y)number
      round(x, decimals = 0)numberHalves round away from zero: round(2.5) is 3.
      sign(x)number−1 for negatives, 1 otherwise — sign(0) returns 1. na gives na.
      max(a, …), min(a, …)numberAny na gives na; non-numbers are ignored; no argument gives E924.
      nz(x, default = 0)valuex, or default if x is na.
      na(x)boolTrue if x is na (na() with no argument is true).
      math.pi, math.enumberConstants.

      Text and numbers#

      Function→Notes
      str(x)textNumbers without useless zeros; a duration as "5s", "5250ms", "1h"; a color as "#rrggbbaa"; a time as nanoseconds; a list as "na"; na as "na".
      str(number, format)textFormat codes: the number of digits after the point sets the decimals ("0.00"); a leading + always shows the sign; a trailing k abbreviates with k or M from 1,000 or 1,000,000 (without abbreviation the decimals are dropped: 950 → "950"); a trailing % multiplies by 100 and adds %.
      str(time, format)textTokens yyyy MM dd HH mm ss SSS, in the chart's display time zone (New York by default).
      len(x)numberLength of a list, text, map, ring or window; na otherwise.
      StrateScript
      print(str(1234.5, "0.0k"), str(0.1234, "0.0%"), str(5, "+0"), str(1500000, "0.00k"), str(950, "0.0k"), str(5s), round(1.256, 2), round(2.5))
// → 1.2k 12.3% +5 1.50M 950 5s 1.26 3

      Other series: request#

      Form→Notes
      request(tf, expr)valueexpr on bars of timeframe tf (text or duration, a multiple of the chart's unit), from the last closed bar.
      request(expr, symbol: "XX")valueexpr on another instrument's one-minute bars.
      request(tf, expr, symbol: "XX")valueBoth.

      Errors E936: wrong arguments, unknown or incompatible timeframe, drawing inside expr, session levels inside expr, no bars for the symbol. See Market data.

      Order flow: of.*#

      Function→
      of.cvd(reset: "session")Cumulative delta; reset "session", "day", "rth", "none" (also "never"). The reset can also be passed positionally: of.cvd("rth").
      of.flow(side = "both", window = 30s)Aggressor volume per second.
      of.trade_count(side = "both", window = 30s)Number of trades.
      of.aggression(window = 30s)(buy − sell) / total.
      of.decay(side = "both", window = 30s)Last third ÷ first third of the window's volume.
      of.burst(side = "both", window: 1s, min_trades: 10)bool.
      of.vpin(bucket, buckets: 50)0 to 1.
      of.ofi(window = 30s)Order flow imbalance at the best prices (order-by-order only).

      Windows longer than flow_history: give E933. See Order flow.
