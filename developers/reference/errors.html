      Reference: errors

      In the StrateScript panel, an error appears in a red box under the editor:

      Text
      Line 3 · "clsoe" is not defined
Did you mean "close"?

      The first line gives the line number and the message; the second, when one exists, a suggested fix. Hover the box's title to see the error code and the column (E930 · column 10). Some errors also come with a one-click Fix: a "did you mean" correction, a negative history index (close[-1] → close[1]), if a = b (→ ==), a missing comma, and a positional argument placed after a named one.

      • E0xx and E1xx are syntax errors: the script cannot be read.
      • E9xx are found while the script runs. The built-in check runs the script on a short synthetic market, so most of them are found before the script reaches the chart. An error in a branch that never runs there appears on the chart when that line first runs.

      While an error remains, the script does not run, and the chart keeps its last valid result.

      • Lexical errors (E0xx)
      • Syntax errors (E1xx)
      • Run-time errors (E9xx)

      Lexical errors (E0xx)#

      CodeMessageCause and fix
      E000Strate engine unreachableNot an error in your script: the app could not reach its script engine, so nothing was checked. Run the script again.
      E001unclosed /* commentClose the comment with */.
      E002unclosed stringA string is missing its closing ", or spans a line break. Strings stay on one line; use \n for a line break.
      E003invalid color: write #RRGGBB or #RRGGBBAAUse 6 or 8 hexadecimal digits.
      E004unknown suffix attached to a number4ticks: write 4 ticks with a space. Duration units (ns us ms s m h d w) are the only suffixes written without a space.
      E005non-ASCII identifier: names are in English, without accentsRename the variable with ASCII letters.
      E006unexpected character 'x'A character the language does not use, such as $, …, → or '.

      Syntax errors (E1xx)#

      CodeMessageCause and fix
      E100expected "x"A symbol is missing. if a = b { is corrected to ==. Also raised for a fn declared inside a block: declare functions at the top level.
      E101expected a nameA name was expected (after fn, type, as…).
      E102expected a stringThe header has no name: strategy "My strategy" { … }.
      E103expected end of statement (new line or ";")Two statements on one line, an unknown word at the start of a line (study "X"), 5 m with a space, or a type annotation without var (x: int = 3).
      E104a single header, placed before the statementsMove the header to the top, or remove the second one.
      E105expected a setting "name: value"In a header, an object or an import override, each entry is name: value.
      E106expected "," or ")"A missing comma (ema(close 20), corrected by Fix), or a unit word after a variable (n ticks: write price(n)).
      E107a type name starts with an uppercase lettertype Zone { … }, not type zone.
      E108a pattern has exactly one "when" clauseAdd the missing when, or merge two into one with and.
      E109"x" needs an initial valuevar x = 0. Fix adds = 0.
      E110missing "}"Close the block.
      E111"x" is only allowed at the top level of the scriptindicator, strategy, research, import, on, pattern, type, enum, method inside a block or a function. Move it to the top level.
      E112cannot assign to this expressionThe left side of = must be a variable, a field of your own type, or a list/map element.
      E113expected ":" in the conditional a ? b : cComplete the conditional.
      E114chained comparisons are not allowed: write a < b and b < c
      E115positional argument after a named argumentPut positional arguments first (Fix does it).
      E116expected an expressionSomething is missing, or a reserved word is used as a name (in = 3), or .5 instead of 0.5.
      E117nested more than 200 levels deepSplit the expression or the blocks.
      E199unexpected declarationA declaration where it is not allowed.

      E915missing argument "p" for f()Pass the argument or give the parameter a default.
      E916unknown type "T"Declare it: type T { field: float }. Also for method T.name without type T.
      E917"self" is only defined inside a method
      E920"op" does not apply to strings / to two durations / to two timesAn operator that does not apply: between two texts (only + and comparisons do), two durations (only +, -, / and comparisons), two times (only - and comparisons), or a time and a duration (only + and -).       E928colors, objects, tablesalpha/mix on a non-color; a time or price of the wrong type for line.new, box.new, label.new; table position, size, cell outside the table, align.

      Examples#

      Each example below fails with the code shown above it, exactly as written.

      <!-- expect: E930 -->

      StrateScript
      indicator "My average" { overlay: true }
length = input.int("Length", 20)
plot(sma(close, lenght))

      <!-- expect: E930 -->

      StrateScript
      if close > open { up = close }
plot(up)

      <!-- expect: E911 -->

      StrateScript
      plot(close[-1])

      <!-- expect: E912 -->

      StrateScript
      plot((close + 1)[1])

      <!-- expect: E921 -->

      StrateScript
      print("close = " + close)

      <!-- expect: E922 -->

      StrateScript
      d = bar.close_time - bar.time
if d > 60 { print("long bar") }

      <!-- expect: E909 -->

      StrateScript
      const k = 2
k = 3

      <!-- expect: E905 -->

      StrateScript
      total += volume

      <!-- expect: E004 -->

      StrateScript
      plot(close + 4ticks)

      <!-- expect: E106 -->

      StrateScript
      n = input.int("Offset", 4)
plot(close + n ticks)

      <!-- expect: E114 -->

      StrateScript
      plot(low < close < high ? 1 : 0)

      <!-- expect: E939 -->

      StrateScript
      strategy "No costs" { overlay: true }
if close > open { enter("buy", stop: 8 ticks) }

      <!-- expect: E939 -->

      StrateScript
      indicator "Not a strategy"
if close > open { enter("buy") }

      <!-- expect: E938 -->

      StrateScript
      indicator "Not research"
pattern "Up" {
  on: bar
  side: "buy"
  when close > open
}
on signal(s) { study(s) }

      <!-- expect: E942 -->

      StrateScript
      indicator "Bad history" { level_history: 45m }
plot(close)

      <!-- expect: E933 -->

      StrateScript
      indicator "Window too long" { overlay: false }
lv = mbo.level(close, window: 3m)
plot(nz(lv.added))

      <!-- expect: E911 -->

      StrateScript
      indicator "Footprint in a handler"
on trade(t) { fp = bar.footprint }

      <!-- expect: E948 -->

      StrateScript
      indicator "Price script" { overlay: true }
plot(volume, overlay: false)

      <!-- expect: E943 -->

      StrateScript
      strategy "No persist" { overlay: true, costs: { commission: 2.5 usd, slippage: 1 tick } }
persist n = 0

      <!-- expect: E934 -->

      StrateScript
      indicator "Typo in pattern"
pattern "P" {
  on: bar
  group: "x"
  when close > open
}

      <!-- expect: E935 -->

      StrateScript
      indicator "No such clock"
on clock fast { print("tick") }

      <!-- expect: E937 -->

      StrateScript
      indicator "Bad import"
import "strate/patterns/absorption_held_volume" as a { minVolume: 90 }
